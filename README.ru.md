# Codaki Android Use

![Codaki — Desktop freedom. Android.](docs/assets/codaki-cover.png)

**Computer Use для Android · Плагин-дополнение для Codaki Mini Codex**

[English](README.md) · **Русский** &nbsp; | &nbsp; **v0.0.2** · [MIT](LICENSE)

**Codaki Android Use дополняет [Codaki Mini Codex — Миникодекс](https://github.com/kalabuxova1-hash/codaki-mini-codex) управлением приложениями Android.** ИИ-помощник читает интерфейс, находит кнопки, вводит текст и проверяет результат на отдельном виртуальном экране через **ChatGPT или Codex и MCP**.

**Аналог подхода Computer Use для Android: увидеть → выполнить → проверить.** Codaki Mini Codex отвечает за системные задачи, файлы и обслуживание телефона. **Codaki Android Use** добавляет работу с интерфейсом внутри приложений.

> **Codaki Mini Codex обязателен.** Сначала установите и настройте его. Codaki Android Use — плагин-дополнение; самостоятельная работа без Миникодекса не поддерживается.

**Свобода действий на Android, как на ПК.** Управляйте телефоном из обычного чата ChatGPT по циклу увидеть → выполнить → проверить: Codaki Mini Codex отвечает за файлы и систему, Android Use — за приложения на собственном экране.

## <img src="https://raw.githubusercontent.com/kalabuxova1-hash/codaki-mini-codex/main/docs/assets/icons/wrench.svg" width="36" height="36" alt=""> Установка Codaki Android Use

### Подготовьте телефон

- **Сначала установите и настройте [Codaki Mini Codex](https://github.com/kalabuxova1-hash/codaki-mini-codex).** Это обязательная основа поддерживаемой установки.
- **Android 16 / SDK 36+**, уже установленные root и Magisk; **Termux с Python 3.10+**.
- ПК с Codex и разрешённым ADB для первоначальной настройки, собственный приватный сервер и подключение плагина.

### Установите через Codex

1. **Скачайте установочный ZIP.** Файл `android-use-codex-setup-0.0.2.zip` доступен в [последнем выпуске](https://github.com/kalabuxova1-hash/codaki-android-use/releases/latest).

2. **Передайте архив Codex на ПК.** Подключите нужный телефон и разрешите USB-отладку. Готовый текст запроса — ниже.

3. **Проверьте подключение плагина.** Попросите открыть настройки на виртуальном экране, прочитать результат и закрыть экран.

<details>
<summary><strong>Показать запрос для установки через Codex</strong></summary>

> Установи Codaki Android Use 0.0.2 из этого архива как дополнение для Codaki Mini Codex на моём подключённом телефоне. Подтверди, что Миникодекс уже установлен и настроен. Прочитай INSTALL_WITH_CODEX.md, проверь требования, создай мой отдельный приватный сервер и подключи плагин. Сервер, ключи и файлы Mini Codex сохрани без изменений.

В архиве есть исходники, готовые Dex JAR-файлы, ADB-установщик и инструкция. Codex нужны доступ к файлам и терминалу, возможности Sites / Plugin Creator. Разрешение USB/root, вход в аккаунт и финальное подключение могут потребовать вашего участия. Установщик не получает root и не устанавливает Mini Codex; его наличие нужно подтвердить до настройки.

Можно передать и один файл [INSTALL_WITH_CODEX.md](https://github.com/kalabuxova1-hash/codaki-android-use/releases/latest/download/INSTALL_WITH_CODEX.md): в нём указаны архив и контрольная сумма.

## <img src="https://raw.githubusercontent.com/kalabuxova1-hash/codaki-mini-codex/main/docs/assets/icons/book.svg" width="36" height="36" alt=""> Документация Codaki Android Use

Откройте нужную тему.

<details>
<summary><strong>Обычный чат ChatGPT, длительное использование и расходы</strong></summary>

Управляйте телефоном через личный плагин Codaki в поддерживаемом чате ChatGPT. Агент выполняет действия локально на Android и не запускает вторую сессию модельного API. Для этого подключения отдельный API-ключ OpenAI не нужен; сам Codaki не берёт плату за токены.

Продолжайте новые задачи и используйте сохранённые решения между чатами. Проект рассчитан на регулярную работу после настройки, но не обещает бесконечную длину чата или непрерывную фоновую работу. ChatGPT по-прежнему использует токены и контекст; действуют [лимиты аккаунта](https://learn.chatgpt.com/docs/pricing). У приватного сервера могут быть собственные расходы.

Цель — широкий доступ к телефону, по духу близкий к Codex на ПК. Реальные возможности зависят от разрешений Android, доступных инструментов и совместимости; полное равенство функций с настольным Codex не заявляется.

</details>

<details>
<summary><strong>Управление приложениями, виртуальный экран и автозакрытие</strong></summary>

- **Отдельный экран с собственным фокусом.** В проверенных сценариях основной дисплей № 0 сохранял фокус, пока приложения работали на виртуальном. У приложений возможны общие эффекты — уведомления, сообщения и изменение данных. Виртуальный дисплей не изолирует данные приложения.
- **Чтение интерфейса.** Встроенный Android `UiAutomation` возвращает тексты, идентификаторы, классы и границы элементов. Кнопки можно выбирать по тексту.
- **Ввод Unicode, включая кириллицу.** Текст вводится в однозначно найденное редактируемое поле. Поля паролей исключены; неоднозначный выбор отклоняется.
- **Скриншоты по необходимости.** PNG-снимки дополняют дерево интерфейса.
- **Меньше обращений к инструментам.** Известные шаги объединяются в пакет; интерфейс читается в точках принятия решения. Телефон повторно использует HTTPS-соединение.
- **Работа без включённого ПК после настройки.** Телефон сам подключается к вашему приватному серверу по HTTPS. Модель работает в ChatGPT или Codex; интернет необходим.
- **Без MagicDesk и отдельного APK проекта.** Core использует Java-компоненты, запускаемые с root, и Python-контроллер. Python предоставляет установленный Termux.
- **Ограниченное время работы дисплея.** Агент освобождает экран после двух минут простоя; у самого дисплея также есть десятиминутная аренда. При удалении его окна уничтожаются, а не переносятся на основной экран.
- **Защита от повторного выполнения.** Авторизация владельца, локальный root-сокет, уникальные идентификаторы запросов и журнал действий позволяют остановиться при неизвестном результате, вместо повторной отправки команды.

</details>

<details>
<summary><strong>Компоненты и команды MCP</strong></summary>

| Компонент | Назначение |
| --- | --- |
| Android Use Core | Управляет виртуальным дисплеем и локальным сокетом, доступным root |
| Java-компоненты | Создают экран, читают интерфейс и вводят текст через `UiAutomation` |
| Агент телефона | Забирает задания по исходящему HTTPS и сохраняет результаты |
| Приватный сервер | Worker + очередь D1, авторизация владельца и MCP |
| Пакет для Codex | Исходники, готовый Dex, контрольные суммы, ADB-установщик и инструкция |

**14 команд Core** и `android_job_result` для незавершённых заданий: проверка возможностей, запуск и остановка экрана, статус, запуск приложений, нажатия, прокрутка, клавиши, окна, скриншоты, чтение интерфейса, нажатие по тексту, ввод текста и пакет действий. Подробнее: [Команды](docs/tools.md), [Архитектура](docs/architecture.md).

</details>

<details>
<summary><strong>Измеренная скорость</strong></summary>

На том же тестовом телефоне после оптимизации:

| Измерение | До | После |
| --- | --- | --- |
| Чтение настроек, медиана трёх измерений | 1 240 мс | 303 мс |
| Запрос по установленному HTTPS-соединению, медиана без первого подключения | 300 мс | 118 мс |
| JSON интерфейса в измеренном окне | 4 778 байт | 3 063 байта |

Два пакета MCP с девятью действиями в настройках заняли **11,0 секунды суммарного времени инструментов**. Рассуждение модели между вызовами сюда не входит. Это **не измерение скорости отправки SMS** и не гарантия для других приложений, сетей или устройств. [Подробности измерений](docs/performance.md).

</details>

<details>
<summary><strong>Совместимость, ограничения и контроль владельца</strong></summary>

**Проверено:** Redmi Turbo 3, Android 16, Magisk и Termux. Другие устройства, работа после настоящей перезагрузки и при защищённой блокировке, а также полная облачная установка новым владельцем пока не подтверждены. Если обязательные флаги дисплея недоступны, Core завершает операцию, не переходя на основной экран.

Виртуальный экран не изолирует данные приложений: возможны изменение данных, отправка сообщений и уведомления. Для отправки сообщения нужна явная просьба владельца с получателем и текстом. После выполнения помощник проверяет результат и освобождает экран.

Mini Codex — обязательное условие поддерживаемой установки. Это требование инструкции; автоматической проверки в установщике и общего сервера компонентов нет.

</details>

<details>
<summary><strong>Разработка и проверка</strong></summary>

Для проверки на ПК нужны Python 3.10+ и Node.js 24+. Для тестов Java-компонента нужны Java/Javac, а для пересборки Dex — D8 из Android SDK.

```sh
npm test
python -m unittest discover -s tests -p "test_*.py"
npm run build
npm run validate
python scripts/package.py
```

Зависимости npm не требуются. В публичном шаблоне нет идентификатора сервера: каждый владелец создаёт свой приватный Site. Ключи, `config.json`, журналы и снимки личных экранов публиковать нельзя.

</details>
