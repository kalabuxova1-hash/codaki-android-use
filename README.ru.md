# Android Use 0.0.1 — отдельный плагин-помощник Codaki Mini Codex

[English](README.md) · [Установка через Codex](INSTALL_WITH_CODEX.md)

**Android Use** дополняет [Codaki Mini Codex](https://github.com/kalabuxova1-hash/codaki-mini-codex) собственным виртуальным экраном Android. Помощник управляет приложениями на отдельном экране, а пользователь продолжает работать на основном.

**Возможности:** запуск приложений, нажатия, свайпы, навигация, снимки экрана, поиск элементов интерфейса, нажатие по тексту, ввод текста и пакетные команды. Контроллер проверяет отдельный экран и не подменяет его физическим.

**Преимущества:** независимость от основного экрана, меньше лишних действий при работе с приложениями, работа после настройки без постоянно включённого ПК. Подключение к ChatGPT возможно через личный защищённый сервер.

**Установка через Codex на ПК:** скачайте репозиторий и передайте Codex файл [INSTALL_WITH_CODEX.md](INSTALL_WITH_CODEX.md). Он проверит телефон, установит компоненты через разрешённый ADB и проведёт проверку. Для размещения файлов предусмотрен `install_with_codex.py`.

**Важно:** root, Magisk и Python в Termux должны быть установлены владельцем заранее. **Мы не устанавливаем root и Magisk**, не разблокируем загрузчик и не меняем прошивку. Для удалённого плагина нужно отдельное личное подключение.

**Версия:** 0.0.1. Исходная сборка проверялась на Android 16; совместимость с другими устройствами требует проверки.

**Поддержать проект:** [добровольное пожертвование на Boosty](https://boosty.to/mini_codexandroid).
